# 母语中文表达（native-chinese-expression）

面向人工智能的语言规则：采用规范、本土化的中文表达，避免"一句话中夹入少量外文单词"的中英混编。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**。

## 有什么用处？

- 让人工智能的回复说纯正中文，不中英文混编、不带翻译腔
- 编写面向中国普通读者（非程序员、非外国读者）的文案、文档或汇报时，给出用词标准

## 为什么要用？

写作的主要目的在于传达意思、便于理解。语言选择中文或英文，其标准在于服务对象。面向中国普通读者的正文以中文为主，不以插入外文体现专业性——读者看不懂的表达，专业性无从谈起。

## 如何用？

1. 先确认服务对象；面向普通读者的正文以中文为主
2. 缩略语与专用词在使用且有助于理解时方予保留，首次出现加中文注释，如：技能（SKILL）、智能体（Agent）
3. 四类保留英文，其余译为中文：产品与技术专有名词、行业通用缩略语、协议名与标准名、代码命令路径文件名
4. 代码块、命令与文件路径中的英文字段名须原文保留（供机器读取，中文可能导致编码错误）

## 速查对照

| 英文词 | 应写为 |
|---|---|
| frontmatter | 文件头字段 |
| manifest | 清单文件 |
| changelog | 版本说明 |
| zip | 压缩包 |
| API | 接口 |
| bug | 缺陷 / 问题 |
